## Projetos

### Data Lake Antifraude | AWS
Data Lake para análise de transações financeiras em um **cenário simulado** de prevenção a fraudes, estruturado em arquitetura Medallion.

**Tecnologias:** Python, Pandas, Amazon S3, AWS Glue, Amazon Athena

- Organização dos dados nas camadas Raw, Silver e Gold
- Tratamento e padronização dos dados
- Armazenamento em formato Parquet
- Tabelas estruturadas para consultas analíticas no Athena

[Ver repositório](https://github.com/SouzaaCarol/data-lake-antifraude-aws)

### Análise de Evasão Escolar em São Paulo
Análise exploratória e estatística da relação entre indicadores socioeconômicos, segurança pública e evasão escolar nos municípios paulistas.

**Tecnologias:** Python, Pandas, Jupyter Notebook

- Integração e tratamento de diferentes fontes de dados públicos
- Análise exploratória e regressão linear
- Interpretação dos resultados, com as limitações estatísticas apontadas

[Ver repositório](https://github.com/SouzaaCarol/evasaoEscolar)

### PaySmart Solutions | Auditoria de Taxas MDR

Projeto de análise de dados voltado à auditoria de cobranças de taxas MDR em transações financeiras, identificando divergências entre valores cobrados e condições comerciais.

**Tecnologias:** SQL, MySQL

- Análise de transações e regras de cobrança.
- Comparação entre taxas aplicadas e taxas previstas.
- Identificação de cobranças acima ou abaixo do valor esperado.
- Classificação das transações em corretas, cobranças indevidas e casos para revisão.

[Ver repositório](https://github.com/SouzaaCarol/auditoria-cobrancas-financeiras)
